Target Repository Configuration

Configure the local path to your separate test repository.

Must be an existing local folder initialized with git init.

How to Create a Disposable Test Repository

Use PowerShell, CMD, or Bash on your computer to create a fresh test repository.

1

Create a test directory

mkdir C:\GitLabs\contribution-test-repo
2

Enter directory & initialize Git

cd C:\GitLabs\contribution-test-repo
git init
3

Copy path into the setting above

Paste C:\GitLabs\contribution-test-repo into the path field and click "Test Path".

🔒 Safety Guarantee:

This application will never perform destructive Git actions silently. It never pushes commits automatically.
